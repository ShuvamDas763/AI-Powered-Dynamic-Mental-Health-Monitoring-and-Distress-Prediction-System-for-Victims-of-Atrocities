# SIH26094 — Intervention Recommendation Table (Research-Grounded, v1)

## Important framing

This table replaces invented placeholder content with recommendations tied to
**real, citable Indian government schemes and legal provisions**. It is a
prototype artifact, not a clinically or legally certified tool. The research
team must review before this is called final.

## Reference frameworks

1. **Witness Protection Scheme, 2018** (MHA/NALSA) — three threat categories:
   A (life), B (safety/reputation/property), C (moderate). Threat Analysis
   Report → Witness Protection Order.
2. **SC/ST (PoA) Rules, 1995** (amended 2011/2014) — staged relief at amounts
   fixed per offence type, plus rehabilitation package.
3. **Dr. Ambedkar National Relief Scheme** — additional central relief (up to
   ₹5 lakh) for heinous offences.
4. **NALSA Compensation Scheme, 2018** + **One Stop Centres** — standard
   institutional referral path for sexual-assault survivors.
5. **SC/ST (PoA) Act, Section 15A(6)** — special court's duty to ensure
   relief/compensation timelines are met.
